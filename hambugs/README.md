## 💻 Sobre o Projeto

O **HamBUG** é uma Landing Page de delivery totalmente temática para desenvolvedores. O conceito foi brincar com o universo da programação, trazendo lanches com nomes de linguagens e tecnologias (como *X-Hello World* e *Full Burger*).

Este projeto foi desenvolvido para praticar conceitos fundamentais do React, como gerenciamento de estados, componentes e manipulação de listas, além da integração direta com a API do WhatsApp para finalização de pedidos.


## ⚙️ Funcionalidades Implementadas

O projeto está finalizado e conta com as seguintes features:

- **Cardápio Interativo:** Listagem dinâmica de hambúrgueres, bebidas e sobremesas através de componentes reutilizáveis.
- **Carrinho de Compras (Lógica de Estado):**
  - O usuário pode adicionar múltiplos itens ao carrinho.
  - O ícone do carrinho atualiza a quantidade de itens em tempo real.
- **Modal de Pedido:**
  - Janela flutuante (Modal) para visualização do resumo do pedido.
  - Cálculo automático do valor total da compra.
- **Checkout via WhatsApp:**
  - O botão de finalizar transforma o array do carrinho em uma mensagem de texto formatada.
  - Redirecionamento automático para o WhatsApp do estabelecimento com o pedido pronto para envio.
- **Responsividade:** Layout adaptável para dispositivos móveis e desktop, utilizando CSS Modules e Sass.

3. Instale as dependências:

-bash

Bash
